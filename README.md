# HR Analytics Dashboard

## 📌 Project Overview
This HR Analytics project focuses on analyzing employee data to identify attrition trends, workforce distribution, and key HR performance indicators. The objective is to understand employee turnover patterns and provide data-driven insights that can support better HR decision-making and employee retention strategies.

## 🎯 Project Objectives
- Analyze overall employee attrition and retention.
- Identify attrition trends across different departments and job roles.
- Understand employee attrition based on age groups, gender, education, and marital status.
- Evaluate employee job satisfaction and workforce demographics.
- Generate meaningful insights to support HR business decisions.

## 🛠️ Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Data Analysis
- Interactive Dashboard

## 📊 Key Performance Indicators (KPIs)
- Total Employees: 1,470
- Total Attrition: 237
- Employee Attrition Rate: 16.12%
- Average Employee Age: 36.92 Years
- Average Job Satisfaction: 2.63

## 🔍 Key Analysis
- Employee attrition by gender.
- Department-wise attrition analysis.
- Job role-wise employee turnover.
- Education-wise attrition trends.
- Age group-wise attrition.
- Marital status-based attrition analysis.
- Employee satisfaction analysis.

## 💡 Key Insights
- A total of 237 employees left the organization.
- The overall employee attrition rate is approximately 16.12%.
- Employees aged 25–34 represent the highest attrition group.
- Single employees account for the highest number of attrition cases.
- Research & Development has the highest share of employee attrition.

## 🚀 Conclusion
This project demonstrates practical HR data analytics skills, including data cleaning, exploratory data analysis, KPI tracking, and interactive reporting. It helps transform raw employee data into actionable insights for workforce planning and employee retention.
